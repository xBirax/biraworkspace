# ADR Workspace 0.1.46-rc.1 — avaliação

- O botão **ADR CRM** no Gmail embutido usa um preload exclusivo e fica acima da
  interface do Gmail. O diagnóstico registra se o painel montou ou falhou.
- **Usar texto do rascunho** reconhece também respostas inline. A leitura só
  ocorre após clique e não envia nem altera mensagens automaticamente.
- ChatGPT disponível em **Adicionar serviço**, com sessão local persistente e
  separada para cada conta. Voz solicita permissão de microfone.
- Ícones de Trello e ChatGPT incluídos no pacote.

Esta é uma candidata para avaliação. Confirmar em Windows o botão do Gmail,
resposta inline, login ChatGPT e persistência de Gmail/CRM/WhatsApp após instalar
por cima da versão existente. Não desinstalar o aplicativo nem apagar seus dados.
O botão **Verificar** oferece apenas versões estáveis.
