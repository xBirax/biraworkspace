# Correções do code review — 13/09/2026

Implementação local, sem publicação ou instalação de nova versão.

## Sete achados tratados

1. Cache de transcrições: autorização renovada no CRM, isolamento por workspace/identidade, invalidação no logout/troca de credenciais e rejeição de operações pendentes após invalidação. Transcrição não usa mais cache local para contornar a API autenticada.
2. Views recuperadas: metadados usam o workspace do serviço. Notificações e abertura do CRM também direcionam para o workspace de origem.
3. PIN: temporizador independente da hibernação, atividade de teclado/mouse com app em foco e verificação de expiração antes de restaurar a view.
4. Atualizador: falha de preparação não reemite download concluído. Timeout de 10 segundos e nova tentativa explícita pela interface.
5. Estado: o backup só recebe bytes de um principal validado e também é substituído atomicamente. Falha de substituição após recuperação preserva a cópia válida.
6. Navegador: URL e histórico são mantidos em memória para restauração após hibernação. Sem persistir histórico/formulários em disco. Recarregamento forçado mantém a página atual do browser.
7. Linux CI: gatilho de tags `v*`, build próprio e preparação do Electron no job de empacotamento.

## Escolha de navegador

Configurações → Geral → Navegador externo preferido: padrão do sistema, Chrome ou Brave. Default novo: sistema. Preferências existentes não são migradas compulsoriamente. Falha ao iniciar um navegador explicitamente escolhido é informada sem abrir outro silenciosamente.

## Evidências

- Testes antes das correções reproduziram sobrescrita de Brave, perda do backup e falhas/repetição do atualizador.
- Suíte completa após as alterações: 257 testes passaram (161 no desktop), em 54 arquivos.
- Build, typecheck, lint e verificação de formatação dos arquivos de código alterados passaram.
- Smoke com Electron real, perfil temporário, janela oculta e rede simulada: uma janela, sete views, shell e CRM carregados, nenhum erro de execução capturado.
- O smoke chamou o IPC real das configurações e confirmou em `state.v1.json` a gravação de `brave`, `chrome` e `auto`, sem abrir navegadores externos.

Não foram usados logins reais, publicados artefatos nem executado o empacotamento Linux neste host Windows. Validação visual/e2e com serviços reais e instalador continua sendo um gate de release. As mudanças preexistentes e `.opencode/` foram preservadas.
